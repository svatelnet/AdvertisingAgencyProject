# AdvertisingAgencyProject

Веб-приложение для автоматизации работы рекламного агентства. Система позволяет вести справочники клиентов и рекламных категорий, оформлять и сопровождать заказы на размещение рекламы, а также разграничивать доступ между администраторами, менеджерами и клиентами.

## Основные возможности

- регистрация и авторизация пользователей через ASP.NET Core Identity;
- автоматическое создание ролей `Admin`, `Manager`, `Client` при запуске;
- автоматическое создание администратора по умолчанию;
- ведение справочника клиентов;
- ведение справочника категорий рекламы;
- создание, редактирование, просмотр и удаление заказов на рекламу;
- личный кабинет клиента;
- отправка клиентской заявки на рекламу;
- автоматический расчет стоимости заказа по базовой цене и длительности размещения;
- автоматическое обновление статусов заказов фоновым сервисом.

## Роли пользователей

### Admin
- управление пользователями;
- создание менеджеров;
- изменение ролей;
- доступ к разделам менеджера.

### Manager
- управление клиентами;
- управление категориями рекламы;
- просмотр и обработка заказов;
- подтверждение и завершение заказов.

### Client
- регистрация в системе;
- редактирование своего профиля;
- подача заявки на размещение рекламы;
- просмотр собственных заказов и их статусов.

## Статусы заказов

В системе используются следующие статусы:

- `Draft` — черновик;
- `Submitted` — заявка отправлена клиентом и ожидает рассмотрения;
- `Approved` — заказ подтвержден менеджером;
- `Active` — заказ активен в текущий период размещения;
- `Completed` — заказ завершен вручную;
- `Cancelled` — заказ отменен;
- `Expired` — срок размещения истек.

Требования по запуску<br>
1. Для локального запуска

    Необходимо установить:<br>

    .NET SDK 10.0;<br>
    Visual Studio 2022 / JetBrains Rider / Visual Studio Code.

    Дополнительно SQLite устанавливать не нужно, так как приложение использует встроенный провайдер Microsoft.EntityFrameworkCore.Sqlite.

2. Для запуска через Docker

Необходимо установить:

Docker Desktop
или
Docker Engine + Docker Compose Plugin.<br>

Как запустить локально

В корне проекта выполнить команды:

dotnet restore AdvertisingAgencyProject/AdvertisingAgencyProject.csproj
dotnet run --project AdvertisingAgencyProject/AdvertisingAgencyProject.csproj

После запуска приложение будет доступно по адресу, который появится в консоли.

Как запустить через Docker

В корне проекта выполнить команду:

docker compose up --build

После сборки и запуска приложение будет доступно по адресу:

http://localhost:8080
Как остановить Docker-контейнер
docker compose down

Для удаления контейнера вместе с volume базы данных:

docker compose down -v
